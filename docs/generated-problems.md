# Pre-generated Echo-checked problems

Status: implementation addendum, 2026-11-13. It supersedes nothing and is linked from `docs/decisions.md`. It does not edit `PLAN.md`, so the approved plan hash (`d8268f20...77d0`) is unchanged. It does change one labeling rule, so it needs a Codex review (see `PLAN-REVIEW-LOG.md`) before the change is final.

User instruction it implements: "The problems should be generated by the following: Generate the answer first; Solve it backwards using LLMs; Generate the problem based on the answer; Verify with SymPy; That would get the 'Echo Checked' label. Each problem should take a few seconds to generate."

## What changed and why

`PLAN.md` and `CLAUDE.md` label a topic Echo-checked only when its verifier passes a topic gate. This addendum labels each problem instead. A problem gets the Echo-checked label when it passes its own SymPy check.

Chain rule and quotient rule problems are generated offline. Every problem is checked before it is saved.

## Method (one problem)

1. **Answer first.** The model proposes a target derivative g(x) in plain SymPy syntax for the topic and level.
2. **Solve backwards.** Given g(x), the model writes a function f(x) whose exact derivative is g(x).
3. **Verify with SymPy.** `sympy.simplify(diff(f, x) - g) == 0` must hold. The rendered problem must also pass `core.derivative_checker.check_derivative`, the same checker a student's answer is checked by. Only then is the problem kept.

Duplicates are rejected by normalized statement. Each problem slot gets up to 12 attempts.

## Scope

- Topics: `chain_rule`, `quotient_rule` (derivative method), and `net_change_total_distance` (integral method). The gate probe in `scripts/gate_topics.py` put the two derivative topics above the power-rule bar.
- Net change method: the model writes an antiderivative F(t) (the answer), then the velocity v(t) = F'(t) with integer bounds 0 <= a < b <= 5 and v >= 0 on [a, b]. SymPy checks v = F', the key F(b) - F(a) against the exact integral, and a numeric check. Net change equals total distance because v >= 0.
- Levels 1 to 4, 10 verified problems per topic and level. Saved: 118 problems (net change L4 has 8; the streak fills the rest from neighbouring levels and the bank).
- Stored in `docs/echo_checked_problems.json`. The app serves them with no model call, in live, replay and fake modes. Bank mode is unchanged.
- Each problem carries the label `Echo-checked: key verified by the checker`, the same label power-rule drafts use.

## Limits (say these in the demo)

- SymPy checks each answer exactly, and the checker that grades a student checks the stored statement again. No human has reviewed these problems.
- The topic chip still says "not Echo-checked". Only the individual problems carry the label. The skill picture does not change.
- Problems use only polynomials, roots, quotients, and e^t for net change, so the reader can read them. Trig and log problems are not generated.
- Verifier fixes from a Codex review (2026-11-13): malformed model output is a failed attempt, not a crash; a stored key must pass the practice checker's text rules, including the 300-character limit.
- The file is regenerated by hand with `scripts/generate_echo_problems.py`. The app never calls the model to make a problem.
